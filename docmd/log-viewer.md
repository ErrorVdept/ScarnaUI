# ScarnaLogViewer

Просмотрщик UTF-8 журнала. Доступна живая страница `/componentlib/log-viewer`.

```razor
<ScarnaLogViewer FilePath="@path" Height="500px" @ref="viewer" />

@code {
    private string path = @"C:\logs\app.log";
    private ScarnaLogViewer? viewer;
    private Task GoToError() => viewer!.GoToLineAsync(120);
}
```

Укажите ровно один источник: `FilePath`, `Text` или `Stream`. Путь читается на сервере.
Поток читается с текущей позиции и остаётся открытым. По кнопке «Обновить» или через
`ReloadAsync()` создаётся новый временный снимок. Для повторного чтения потока приложение
должно самостоятельно вернуть его позицию к началу. Временный файл удаляется при закрытии компонента.

`IncludePattern` и `ExcludePattern` — регулярные выражения .NET. Пустой параметр отключает
правило. `FilterIgnoreCase` отключает учёт регистра, `FilterMultiline` включает обработку
выражения по всему тексту. В многострочном режиме совпадение относит к фильтру все
затронутые строки. Для совпадений действует ограничение времени в две секунды.

Поиск работает по всему снимку, включая скрытые строки. Строка, к которой выполнен
переход, временно добавляется в список. Точка слева от номера выбирает или снимает
выбор строки; Shift-клик по точке добавляет диапазон. Поиск открывается кнопкой или
сочетанием Ctrl+F для активного просмотрщика; при фокусе в другом поле ввода сочетание
не перехватывается. Esc закрывает панель, Enter
и Shift+Enter переходят по совпадениям. Контекстное меню копирует текстовое выделение,
строку или выбранные строки.
Текущая строка результата поиска подсвечивается отдельно от выбранных точками строк.
Выделение сохраняется при прокрутке за пределы экрана; Ctrl+C копирует выделенный
текст или отмеченные точками строки, даже когда они не отображаются.
`ContextMenu` принимает `RenderFragment<ScarnaLogContext>` с номером и текстом строки;
`LineSelected` вызывается при выборе номера строки.

Многострочный поиск и фильтры создают временную UTF-16 копию снимка на диске и используют
отображение файла в память; для неё требуется свободное место. Максимум — 2 147 483 647
UTF-16 символов. Отображённые страницы файла также занимают системную память при работе.

Текущие ограничения: высота ещё не посещённых строк при переносе оценивается приблизительно и уточняется
при отображении. Подсветка совпадений доступна для однострочного поиска; подсветка
многострочных совпадений и синтаксиса пока не реализована. Не передавайте `FilePath` из недоверенного ввода без проверки доступа.
